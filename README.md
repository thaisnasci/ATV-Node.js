# Projeto Pokémon - Node.js

Aplicação web desenvolvida com Node.js, Express e EJS utilizando arquitetura MVC.

## Funcionalidades
- Página inicial
- Pokédex com tabela de Pokémons
- Histórico de batalhas
- Perfil do treinador

## Observação
Os dados foram simulados considerando as mecânicas de tipos e o universo Pokémon.
